# RescueLink Application Screenshots & Visual Showcase

This directory contains the visual showcase images for RescueLink.

- **dashboard.png**: Dashboard screen with live incident counters and local Risk Score calculation.
- **create_incident.png**: Incident Reporting Form with GPS capture, photo picker & compression pipeline, and deterministic priority calculator preview.
- **map.png**: Interactive cartography using OpenStreetMap tile layers with priority color-coded markers and critical risk zones overlay.
- **profile.png**: Profile management screen with dynamic FR/EN language switcher, Light/Dark/System theme selector, and High Contrast accessibility mode.
